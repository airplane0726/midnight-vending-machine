# 午前0時の自販機 第1話「雨のしかく」

> 午前0時、光ったボタンから出てきたのは、中だけで雨が降る透明な立方体だった。

- 形式: 縦型 9:16 / 20秒 / 5カット（3秒・4秒・4秒・5秒・4秒）
- ナレーション・せりふ・字幕なし（表情・動作・効果音・音楽で伝える）

## あらすじ

午前0時、古い自販機の下段右端のボタンが1つだけ光る。ポコがつま先立ちで押すと、取り出し口に透明な立方体が落ちてくる。立方体の中だけで細かな雨が降っていて、傾けると雨も一緒に傾く。思い切って逆さにすると、雨は上へ昇り、ポコの体もふわりと浮き上がる。慌てて元の向きに戻すとポコはゆっくり着地し、足元の石畳に小さな虹が残る。その様子を、取り出し口のフラップの陰から白い生き物モチがそっとのぞいていた。

## 不思議な品物：雨のしかく

透明なガラスのような立方体。一辺はポコの胴体の幅の半分ほどで、ポコが両腕で胸の前に抱えて持つ大きさ。中では細かな雨が降り続けている。

**性質（以後変更しない）**

- 中だけで細かな雨が降り続けている。水は外に漏れず、底に落ちた雨粒は小さくはねて消える（水はたまらない）。
- 雨は常に立方体自身の『底面』へ向かって降る。立方体を傾けると、雨も同じ角度で傾く。
- 逆さにすると雨は上へ昇り、立方体を持っている者の体がゆっくり浮き上がる。
- 元の向きに戻すと浮く力が消え、持っている者はゆっくり降りて着地する。
- 浮いたあとに着地すると、その足元に小さな虹が残る。

## 音楽（全体）

- **overall**: オルゴールの単音から始まる、かわいく少し不思議な20秒の小品。途中で一瞬宙づりになり、最後は元の調に戻ってふわっと終わる。最後の音がカット1の冒頭につながるループ可能な構成。
- **bpm**: 84
- **key**: ヘ長調（浮く場面だけ全音音階の響き）
- **instrumentation**: オルゴール、ピチカートのコントラバス、グラスハープ（ワイングラスの縁をこする音）、ごく小さなチェレスタ
- **structure**: 0〜3秒 オルゴール単音 / 3〜11秒 ピチカートが加わり雨のリズムと同期 / 11〜16秒 低音が抜けグラスハープの持続音が上昇 / 16〜20秒 オルゴールが主旋律に戻り、虹とともに和音で解決、最後は自販機の作動音だけ残る

## カット1「光るボタン」 3秒（0〜3秒）

- 登場: ポコ
- カメラ: 正面からのやや低いアングル（ポコの目の高さより少し下）。カメラは自販機の正面に向き、壁の時計から石畳のポコの足元までを縦長に収める。自販機は画面の中央から右寄り、ポコは画面左下で自販機の正面に重なって立つ。画面下端はポコの足元のすぐ下（手前の石畳は画面の1割程度まで）。固定カメラ。
- 前からのつながり: 話の開始状況：午前0時直前、取り出し口の画面左半分の前（自販機から1歩手前）にポコが立ち、ボタンはどれも光っていない。
- 足の接地: 開始時は両足とも石畳に接地。1.1〜2.0秒は交互に1歩ずつ（常に片足は接地）。2.0秒以降は両足のつま先が接地。

**開始画像**

深い青の夜。石畳の路地の角、しっくい壁の前に、くすんだ水色の古い自販機がカメラの方を向いて画面の中央から右寄りに立ち、陳列窓の内側上部の古い蛍光灯が暖かく灯っている。自販機の上の壁の丸い掛け時計は、2本の針が真上で重なっている（午前0時）。陳列窓の右側のボタン盤（3段×4列の丸いボタン）はまだどれも光っていない。ポコは自販機の横ではなく正面にいる：取り出し口の画面左半分の前、自販機から1歩手前の石畳の上に両足をそろえて立ち、カメラから見るとポコの体が取り出し口のフラップの左半分に重なっている。ポコの大きさの目安：頭のてっぺんは陳列窓の中段の棚の高さ、下段のボタンの列はポコの目と頭のてっぺんの間の高さ、取り出し口のフラップの上端はポコの胴の中ほどの高さ。下段右端のボタン（ボタン盤の右端）は、ポコから見て画面右へ自分の体の幅2つ分ほど離れている。体は画面右（ボタン盤の方）を向き、少しだけカメラ側へ振り向いているので、顔（横長の目）と、ポコ自身の左半身がカメラから見える。ボタン盤を見上げ、木の腕は体の横。赤いバッグのベルトは、ポコ自身の右肩（カメラから遠い側）から胸の前を斜めに横切って、ポコ自身の左腰（カメラ側）のバッグへ下りている。ふたは閉じている。画面左奥に街灯の暖かい光。

**動き**

- 0.0秒〜0.5秒: 静止。自販機の低い作動音だけが鳴っている。
- 0.5秒〜0.8秒: 下段右端のボタンが1つだけ、ぽうっと琥珀色に光る。光がポコのクリーム色の体にほんのり映る。
- 0.8秒〜1.1秒: ポコの横長の目が縦に少し大きくなり（驚き）、体がわずかに後ろへ傾いてから戻る。
- 1.1秒〜2.0秒: ポコが自販機の正面に沿って画面右へ小さく2歩進む（ポコ自身の右足、左足の順。1歩で体の幅の半分ほど）。光るボタンの真下、取り出し口の画面右半分の前で止まり、その場で自販機の正面に向き直る（カメラにはポコの背中と、斜め後ろからの横顔が見える）。バッグが歩みに合わせて小さく揺れる。
- 2.0秒〜2.4秒: つま先立ちになり、ポコ自身の右腕（画面右側）を頭の横から真上へいっぱいに伸ばす。下段のボタンは頭のてっぺんより少し低い位置なので、腕の先がちょうど届く。
- 2.4秒〜3.0秒: 光るボタンをポコ自身の右腕の先で押す。ボタンは光ったまま。ポコはつま先立ちで右腕を伸ばした姿勢で止まる。

**終了状態**: ポコは取り出し口の画面右半分の前、光るボタンの真下で、自販機の正面を向いてつま先立ちになっている（カメラにはポコの背中側が見える）。ポコ自身の右腕（画面右側）を真上に伸ばし、陳列窓の右側のボタン盤の下段右端の光るボタンに触れている。ポコ自身の左腕（画面左側）は体の横。バッグはポコ自身の左腰（画面左側）。取り出し口のフラップはポコの脚の前にあり、上端はポコの胴の中ほどの高さで、画面左へも広がっている。

**音**

- 環境音: 自販機の低い作動音（ブーン）、遠くでかすかな夜風。全編を通して小さく続く。
- 0.5秒: ポーン — ボタンが光る、やわらかい鐘のような一音
- 1.2秒: トコ — ポコの足音（丸い木の足が石畳に当たる軽い音）
- 1.7秒: トコ — 2歩目の足音
- 2.4秒: カチッ — 古いボタンが押し込まれる硬い音
- 音楽: 0.5秒の『ポーン』と同じ音程で、オルゴールの単音がゆっくり3音だけ鳴る。

## カット2「落ちてきた立方体」 4秒（3〜7秒）

- 登場: ポコ
- カメラ: ミディアムショット。カメラはカット1と同じく自販機の正面側、やや画面左寄りの低い位置から、下段のボタンから取り出し口までの自販機の下側と、ポコの全身をとらえる。開始時のポコは自販機の方を向いているので、ポコの左斜め後ろから見る形になる。固定カメラ。
- 前からのつながり: カット1の終了状態：光るボタンの真下（取り出し口の画面右半分の前）で自販機の正面を向き、つま先立ちでポコ自身の右腕を伸ばしてボタンに触れているポコ。
- 足の接地: 0.4秒でかかとを下ろし両足接地。その後は足の位置を変えない。かがむ間も両足の裏は石畳から離れない。立ち上がりながらその場で向きを変える（足を小さく踏みかえるが、常にどちらかの足は接地）。

**開始画像**

自販機の下側のアップ（下段のボタンから取り出し口まで）。陳列窓の右側のボタン盤の、下段右端のボタンが琥珀色に光っている。ポコは光るボタンの真下で自販機の正面を向き、つま先立ちでポコ自身の右腕（画面右側）を真上に伸ばしてボタンに触れている。カメラからはポコの背中と左半身が見え、バッグはポコ自身の左腰（画面左側、カメラ寄り）にある。黄ばんだ半透明のフラップが付いた横長の取り出し口は、ポコの脚のすぐ前にあり、上端はポコの胴の中ほどの高さ。画面上ではポコの前から画面左へ広がっている。ポコはまだ腕を下ろし始める直前。

**動き**

- 0.0秒〜0.4秒: ポコがポコ自身の右腕を下ろし、つま先立ちからかかとを下ろして両足で立つ。
- 0.4秒〜0.7秒: ポコの目の前、取り出し口の中に何かが落ち、フラップが内側から小さく揺れる。ポコが下を見る（その場で向きは変えない）。
- 0.7秒〜1.5秒: ポコがその場で少しかがみ、ポコ自身の左腕で目の前のフラップを押し上げて、中をのぞき込む。
- 1.5秒〜2.6秒: 両腕で透明な立方体を取り出す。フラップがぱたんと閉じる。立方体を両腕で胸の前に抱えたまま、ゆっくり立ち上がりながら、その場で体をカメラの方へ向き直す。同時に、光っていたボタンの灯りがすっと消える。
- 2.6秒〜4.0秒: カメラの方を向いたポコの胸の前で、立方体の中に細かな雨が真下に降っているのが見えてくる。ポコは顔を近づけてのぞき込み、目が縦に大きくなる。雨粒の光がポコの目に映る。

**終了状態**: ポコは取り出し口の画面右半分の前（光っていたボタンの真下、同じ位置）で、体をカメラの方へ向けて両足をそろえて立っている。透明な立方体を両腕で胸の前にまっすぐ（傾けずに）抱え、中の雨をのぞき込んでいる。カメラの方を向いたので、ポコ自身の右側が画面左、ポコ自身の左腰のバッグが画面右に来る。閉じた取り出し口はポコの背後で、画面上ではポコの背後から画面左へ広がっている。ボタンの灯りは消えている。

**音**

- 環境音: 自販機の低い作動音が続く。
- 0.4秒: ゴトン — 取り出し口に品物が落ちる、こもった重めの音
- 0.5秒: カタカタ — フラップが小さく揺れる音
- 1.0秒: キィ — 古いフラップを押し上げるきしみ
- 2.0秒: パタン — フラップが閉じる軽い音
- 2.6秒: サァァ（小） — 立方体の中の細かな雨音。ガラス越しのようにこもった小さな音で、以後この雨音は立方体を持っている間ずっと続く
- 3.4秒: ピコ — ポコの小さな電子音（驚き）。言葉ではない短い一音
- 音楽: 2.6秒の雨音と同時に、ピチカートのコントラバスが雨粒のように軽く入る。オルゴールは短い上昇フレーズ。

## カット3「傾く雨」 4秒（7〜11秒）

- 登場: ポコ
- カメラ: ポコの上半身と立方体のアップ（バストショット）。カメラの方を向いたポコを正面からやや画面左寄りに撮る。背景に自販機の水色がぼける。固定カメラ。
- 前からのつながり: カット2の終了状態：取り出し口の画面右半分の前でカメラの方を向いて両足で立ち、立方体を胸の前にまっすぐ抱えて中の雨をのぞき込むポコ。
- 足の接地: フレーム外だが両足とも接地したまま（足は動かさない）。

**開始画像**

ポコの上半身と立方体のアップ。ポコはカメラの方を向き、両腕で透明な立方体を胸の前にまっすぐ抱え、のぞき込んでいる。立方体の中では細かな雨が真下に降り、底で小さくはねて消えている。ポコの横長の目は少し縦に大きく、雨の光が映っている。背景には自販機の水色と陳列窓の暖かい光がぼけている。赤いバッグのベルトがポコ自身の右肩（画面左側）にかかっている。

**動き**

- 0.0秒〜0.5秒: 立方体をまっすぐ抱えたまま、雨が真下に降るのをじっと見る。
- 0.5秒〜1.8秒: ポコが立方体をゆっくり画面左（ポコ自身の右側）へ約30度傾ける。中の雨も立方体と同じ角度で斜めに降るようになる（立方体の底面へ向かって降る）。ポコの体も同じ方向へ少し傾く。
- 1.8秒〜2.3秒: 傾けた姿勢のまま止まり、ポコの目が丸く縦長になる（不思議がる）。
- 2.3秒〜3.6秒: 今度は反対の画面右（ポコ自身の左側）へ、まっすぐを通り越して約30度傾ける。雨も同じように傾く。ポコの体も画面右へ傾く。
- 3.6秒〜4.0秒: 画面右へ30度傾けた姿勢で止まる。ポコの目が少し細くなる（何か思いついた表情）。

**終了状態**: ポコはカメラの方を向いて両足で立ったまま、立方体を画面右（ポコ自身の左側）へ約30度傾けて胸の前に抱えている。雨は立方体の底面へ向かって斜めに降っている。ポコの体も少し画面右へ傾いている。

**音**

- 環境音: 自販機の作動音（小）。立方体の中の雨音が続く。
- 0.6秒: キュ — ガラスの立方体を持ち直す小さなこすれる音
- 1.0秒: サァァ（左へ移動） — 雨音が傾きに合わせて左へパンする
- 2.4秒: キュ — 反対へ傾け始める音
- 2.9秒: サァァ（右へ移動） — 雨音が右へパンする
- 3.7秒: ピ — ポコの短い電子音（ひらめき）
- 音楽: ピチカートが雨のリズムを刻み、傾けるたびにオルゴールが下降（左）・上昇（右）する短い音型を鳴らす。

## カット4「逆さの雨」 5秒（11〜16秒）

- 登場: ポコ
- カメラ: ミディアムロングショット。カメラの方を向いたポコを、画面左手前寄り（ポコ自身の右斜め前）から撮る。ポコの全身と頭上の空間、背後（画面右寄り）に自販機の下半分。浮き上がるポコに合わせてカメラがわずかに上へ動く。
- 前からのつながり: カット3の終了状態：カメラの方を向いて両足で立ち、立方体を画面右へ約30度傾けて抱えるポコ。
- 足の接地: 0〜1.0秒は両足接地。1.0〜1.3秒でかかと→つま先の順に離れる。以後は浮遊（立方体を逆さにしている作用によるもの）。終了時も浮いたまま。

**開始画像**
