# 全自動化までの残り作業（2026-11-24 時点）

方針: 3日に1本、月 3,000円以内（1本 原則 300円）。制作は自動化し、投稿前に利用者が確認する。

## 1本あたりの費用の目安（作り直しなし）
| 工程 | 方法 | 見込み |
|---|---|---|
| 台本 | Claude Code（既存の契約） | 0円（上限の対象外） |
| 画像 5枚 | OpenAI gpt-image-2.6-sunburst（参照3枚） | 約 $0.42 ≒ 66円 |
| 動画 5本 | Runway Gen-4 Turbo 5秒（未検証） | 約 $1.25 ≒ 200円 |
| 音・編集・保存 | ffmpeg・Google ドライブ（無料枠） | 0円 |
| 合計 | | 約 266円（月10本で約 2,660円） |

作り直しに使える余裕は月 約 340円しかない。画像の品質設定を下げる、動画を一部のカットだけにする、などの調整が必要になる可能性が高い。

## 残り作業
1. 動画: Runway の入金・API キー登録 → カット4で技術確認（$0.25）。立方体を元に戻して着地するまでのつながりをどこで見せるかは未解決。
2. 音: 音楽・効果音の調達方法（自作・利用条件の確認済み素材・合成）を決め、20秒の音声トラックを作る処理。
3. 編集: 5本の動画と音声を結合して 1080×1920・20秒に書き出す処理（ffmpeg。animatic を拡張）。
4. 確認用パッケージ: 完成動画・投稿文・費用をまとめて利用者に渡し、承認を受ける手順。
5. 投稿: YouTube・Instagram への投稿処理（下記の確認が先）。認証は Google ドライブと同じく GitHub Actions のシークレットに置く方式を想定。
6. 定期実行: 3日ごとに制作を始める予約（予算の残りと前回の承認状態を確認してから始める）。

## 投稿先について確認が必要なこと
- YouTube: YouTube Data API の有効化と、投稿用の権限（youtube.upload）の承認。審査を受けていない API プロジェクトから投稿した動画は「非公開」に制限されるため、非公開で投稿 → 利用者が確認して公開、の流れが合う（要確認）。AI で作った内容の申告の扱い。
- Instagram: プロアカウント（ビジネス／クリエイター）への切り替え、Meta の開発者アプリとリール投稿の権限、トークンの保存場所。API では下書きがなく投稿すると即公開になるため、確認は API で送る前に行う。動画は公開 URL から取り込まれるため、一時的な公開の置き場所が必要。
- 両方: 投稿の頻度と時刻、ハッシュタグ・説明文のルール、AI 生成の表記。
