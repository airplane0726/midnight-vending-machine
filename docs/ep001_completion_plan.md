## 方針

- 同じカットの動画試作は繰り返さない。カット4の2回目の試作は取り消し済み（未実行・費用なし）。
- 動画生成（Runway）は使わない。採用済みの5枚＋新しい静止画4枚を、無料の編集・合成（ffmpeg）でつなぐ「動く絵本」方式。

- 音（効果音・環境音・音楽）は ffmpeg で合成して作る（無料・権利の心配なし）。
- 世界観・人物設定・原因と結果・モチがのぞく結末は維持する。

## 元の案との違い

1. カット1：2歩進む動きは見せず、足音と絵の切り替えで表す。驚いて目が大きくなる動きもなし。
2. カット2：取り出し口から立方体を取り出す動作は見せない（ゴトン・キィ・パタンの音でつなぐ）。カメラの方へ向き直る動きもなし。
3. カット3：画面左へ傾ける動きは省き、画面右へ傾けた絵（K4）だけで「雨も傾く」を見せる。
4. カット4：回す動作そのものは切り替え効果で表す。浮く高さは身長の半分→3分の1。足元を見下ろして慌てる表情は省く（電子音ピピッで表す）。
5. カット5：降りてくる動きは溶け合わせと小さな揺れで表す。モチのまばたきは音だけ。
6. 動きは「絵の切り替え＋合成」なので、本物のアニメーションよりは紙芝居に近い見た目になる。
