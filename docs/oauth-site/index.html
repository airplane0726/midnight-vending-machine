midnight-vending-machine

個人の創作連載「午前0時の自販機」を制作するための、個人用の制作ツールです。 生成した画像などの制作素材を、利用者本人の Google ドライブに保存・復元するために Google のアカウント連携を使います。 一般公開のサービスではなく、利用者は開発者本人のみです。

プライバシーポリシー

  • 取得する権限：Google ドライブの drive.file スコープのみ。このツールが作成したファイルとフォルダーだけにアクセスし、それ以外のドライブ内のファイルは読み取りません。
  • 利用目的：このツールが作成した制作素材（画像・動画など）の保存、空き容量の確認、保存した素材の復元。
  • 保存場所：素材は利用者本人の Google ドライブ内のフォルダーに保存されます。第三者のサーバーへ素材やアカウント情報を送信・販売・共有することはありません。
  • 認証情報：アクセストークンは処理中のメモリ上でのみ使用し、ログやソースコードに記録しません。
  • 連携の解除：Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/permissions）からいつでも解除できます。
  • お問い合わせ：Google Cloud の同意画面に登録したサポートメールアドレスまで。
